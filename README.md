# LAKBAY — Philippines Travel Website Mockup

A responsive HTML/CSS/JavaScript recreation inspired by the supplied dark editorial outdoor/travel reference layout.

## Files
- `index.html` — page structure/content
- `style.css` — all styling and responsive layout
- `script.js` — menu, slider, favorites, search, newsletter interactions
- `assets/` — the supplied destination images

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Notes
- The layout is original and uses the supplied images as destination photography.
- The navigation, destination slider, favorites, mobile menu, search prompt, and newsletter form have basic JavaScript interactions.
- Replace text, links, and destination data in `index.html` as your project develops.
